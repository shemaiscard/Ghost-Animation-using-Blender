# Assets and licensing

The MIT licence in [LICENSE](LICENSE) covers the **code** in this repository: the Python
and shell scripts under `scripts/`. Art assets are listed separately below, because MIT is
a software licence and applying it blanket-style to a `.blend`, a render and an audio file
is not meaningful.

## What ships here

| Asset | Origin | Licence |
|---|---|---|
| `Ghost.blend` | Original coursework scene, authored by Shema Nkindi Giscard | CC BY 4.0 |
| `Ghost_v2.blend` | Rebuilt scene, generated by `scripts/improve_ghost.py` from `Ghost.blend` | CC BY 4.0 |
| `assets/audio/ghost_bed.flac` | Synthesised from oscillators and noise by `scripts/make_audio.sh` | CC0 1.0 |
| `renders/ghost_v2.mp4` | Render of `Ghost_v2.blend` | CC BY 4.0 |
| `scripts/*` | This repository | MIT |

There are **no third-party art assets in this repository.** That is deliberate, and it is a
change from the first version.

## What was removed, and why

**`fullmoon.hdr`.** The original `Ghost.blend` referenced an environment texture at
`//../Documents/fullmoon.hdr` with `packed_file = None`. The path pointed outside the
project directory, used Windows separators, and the file was never committed. Anyone who
cloned the repository opened a scene with no environment lighting, which is why the old
README asked the reader to go and download their own HDR from Poly Haven. The dependency is
gone: `Ghost_v2.blend` builds its night sky from a procedural Sky Texture node, so there is
no external image to find, pack, license or credit.

**`Horror Sound Music (mp3cut.net) (1).mp3`.** The original scene had this in the Video
Sequence Editor. It was also unpacked, so it was missing on clone. Beyond that, a clip
pulled from an mp3-cutting site has unknown provenance: there is no author, no source and no
licence, and it was being redistributed here under MIT. It has been removed.
`assets/audio/ghost_bed.flac` replaces it and is generated from scratch by
`scripts/make_audio.sh`, so it carries no third-party terms.
